# Nailous スキャン ロードマップ（多角度写真・動画）

オーナー要望（2026-09-13）: 1枚の写真では爪の立体（縦アーチ・横Cカーブ・厚み・先端）が取れない。
上／横／逆の横／猫の手（握った時の上）の4素材、または動画から自動で爪をモデリングしたい。

## 方針: 写真測量ではなくパラメトリック推定

- 爪は小さく光沢があり、Object Capture（写真測量）は LiDAR と数十枚を要し、爪単体では破綻する。
- Nailous の爪は既にパラメトリック（`NailPlateParams`: length / width / curveH / curveV / thickness / corner）。
  **各角度の写真から対応するパラメータを推定し、上面写真をテクスチャにする**のが現実的で、失敗しても手動調整に落とせる。

| 角度 | 見えるもの | 推定するパラメータ |
| --- | --- | --- |
| 上（真上） | 輪郭・先端の丸み・デザイン | shape の候補, length/width 比, corner, **テクスチャ** |
| 横 | 縦アーチ・フリーエッジの厚み | curveV, thickness |
| 逆の横 | 同上（左右非対称の検証・平均化） | curveV, thickness の信頼度 |
| 猫の手（握った上） | 断面のCカーブ・先端のライン | curveH, corner の裏取り |

## Phase 1: 4方向ガイド撮影と保存（UI）
- `NailCameraView` に「立体スキャン」モード: 4ステップのガイド（上→横→逆の横→猫の手）。各ステップに枠とヒント、撮り直し可。
- `NailRecord.anglePhotoData: [Data]`（4スロット, 長辺1600 JPEG）。上面は従来どおり切り抜き→テクスチャ。
- 詳細画面に「角度別の写真」ストリップ。再スキャンからも同じフローに入れる。
- 受け入れ: 4枚が保存され再表示できる。上面だけでも完了できる（残りは任意）。

## Phase 2: 写真からのパラメータ自動推定
- 前処理: `VNGenerateForegroundInstanceMaskRequest` で被写体、`NailCleanup` の肌モデルで爪/肌を分離。
- 上: 爪マスクの輪郭 → 幅関数 w(t) を `NailGeometry.widthFactor` の各 shape と最小二乗で照合 → shape, corner。長さ/幅比 → length, width。
- 横: 爪の上縁の曲線を2次で当てはめ → 曲率から curveV。先端の厚み（エッジの2本線の距離 / 爪長）→ thickness。
- 猫の手: 先端ラインの弧の矢高 / 弦 → curveH。
- 信頼度が低い項目は推定しない（手動のまま）。推定値は「調整」シートに「自動推定」バッジ付きで入り、ユーザーが上書きできる。
- 検証: `ios/BenchmarkAssets` に角度別サンプルを追加し、`scripts/bench-detect.sh` と同様にホストで回帰。

## Phase 3: 動画スキャン
- 5〜8秒の動画（手を回す／カメラを回す）。`AVAssetImageGenerator` で 8fps 抽出。
- `VNDetectHumanHandPoseRequest` で指軸と見え方（上/横/握り）を分類し、各角度のベストフレーム（ブレ最小・爪面積最大）を自動選出 → Phase 2 へ。
- 選出に失敗したフレームは手動選択にフォールバック。iOS シミュレータでは手検出が動かないため実機／ホスト検証。

## 非目標
- メッシュの再構成、法線マップの生成。パラメトリックで表現できない造形（3Dパーツ等）は対象外。
